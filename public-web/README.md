# Appointment Assistant Public Web

Public website and demo frontend for Appointment Assistant.

## Stack

- React
- TypeScript
- Vite
- ESLint
- pnpm

## Setup

```bash
pnpm install
```

## Development

```bash
pnpm dev
```

## Validation

```bash
pnpm lint
pnpm build
```

## Production Preview

```bash
pnpm preview
```
