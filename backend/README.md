# Appointment Assistant Backend

Laravel backend for Appointment Assistant.

## Stack

- PHP 8.3+
- Laravel 13
- PostgreSQL
- Redis
- PHPUnit

## Setup

Install dependencies and initialize the application:

```bash
composer setup
```

## Development

Start the Laravel development server:

```bash
php artisan serve
```

## Tests

Run the backend test suite:

```bash
composer test
```

## Code Style

Format the backend code with Laravel Pint:

```bash
./vendor/bin/pint
```
